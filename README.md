# Servicios Técnicos - Sistema de Gestión

## Descripción
Aplicación web full-stack para administrar clientes, técnicos y servicios técnicos.

## Tecnologías Utilizadas
* **Frontend:** React, JavaScript, CSS, Vite
* **Backend:** Python, Flask, Flask-CORS, MySQL Connector
* **Base de Datos:** MySQL
* **Pruebas de API:** Thunder Client

## Requisitos Previos
* Node.js (v18+)
* Python (v3.10+)
* Servidor MySQL (XAMPP)

## Ejecución del Proyecto

### Backend:
```bash
cd backend
venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
